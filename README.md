# KK1 – Analys av svensk kriminalstatistik

## Om projektet
Analys av svensk brottsstatistik från BRÅ (Brottsförebyggande rådet) 
med data från 1950 till 2025.

## Dataset
Källa: Brottsförebyggande rådet (BRÅ)
Fil: data/10La_anm2_fr1950.xlsx
Innehåller anmälda brott per 100 000 invånare uppdelat på brottstyp.

## Hur man kör notebooken
1. Klona repot
2. Skapa virtuell miljö: python -m venv venv
3. Aktivera: venv\Scripts\activate
4. Installera: pip install pandas numpy matplotlib seaborn openpyxl
5. Öppna notebook.ipynb i VS Code
